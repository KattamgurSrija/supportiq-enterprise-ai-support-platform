
# SupportIQ – Enterprise AI Support Intelligence Platform

## Overview

SupportIQ is an AI-powered customer support platform built using Java, Spring Boot, Angular, and Generative AI.

The platform helps support teams manage customer tickets, retrieve relevant knowledge, investigate issues, and generate accurate customer responses.

## Project Goals

- Build scalable REST APIs using Spring Boot.
- Implement Retrieval-Augmented Generation (RAG).
- Integrate Large Language Models using Spring AI.
- Build controlled agentic AI workflows.
- Provide human approval for important actions.
- Track AI response quality and performance.

## Technology Stack

- Java 21
- Spring Boot
- Spring AI
- Angular
- PostgreSQL
- pgvector
- Amazon Bedrock
- Git and GitHub

## Main Features

1. Ticket Management
2. AI Knowledge Assistant
3. Intelligent Ticket Classification
4. AI Response Generation
5. Human-in-the-Loop Approval
6. Support Analytics
